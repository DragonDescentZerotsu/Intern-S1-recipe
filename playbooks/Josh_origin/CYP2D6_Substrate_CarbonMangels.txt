# CYP2D6 Substrate Assessment

## This guide helps guide a probability P (0-100) assessment for the task.
Probability the molecule is metabolized by CYP2D6. Key recognition motif: protonatable/basic nitrogen (cationic at pH 7.4) + hydrophobic/aromatic features + characteristic topological separation between basic N and site of metabolism (~5-7 Å).

## Gate rules (hard overrides, apply first)
- No positive states at pH 7.4 AND net charge ≤0: ceiling ≤25
- Predominantly anionic (negative states, no positive): ceiling ≤10
- MW >600: ceiling ≤40

## Scoring (Base score = 10)

### A) Ionization / charge (max +45, min -40)
- has_positive_states: +35
- Representative net_charge ≥+1: +10 more
- has_negative_states AND no positive: -40
- Zwitterionic/ambiguous: +10

### B) Aromatic & ring content (max +20, min -10)
- aromatic_rings ≥1: +10; ≥2: +5 more; total_rings ≥3: +5 more
- aromatic_rings==0 AND total_rings ≤1: -10

### C) Aryl-alkyl-amine spacing proxy motifs (max +20)
- Any aryl_2C_to_amine / aryl_3C_to_amine / aryl_ether_2C_to_amine / phenoxypropanolamine_like: +15
- 2+ present: +5 more

### D) Lipophilicity (max +15, min -15)
- logP 1.5-5.0: +15; 0.5-1.5: +5; <0.5: -10; >6.5: -15

### E) TPSA (max +10, min -25)
- 15-60: +10; 60-90: +0; 90-120: -10; >120: -25

### F) Size (max +10, min -20)
- MW 180-450: +10; <120: -10; >600: -20

### G) Amide penalty
- ≥1 amide bond: -8; ≥3: -15

### H) Strong acid penalty
- Carboxylic acid or strong acids: -25

### Calibration floor
- If cationic + aromatic≥1 + logP 1.5-5 + TPSA ≤60: prob = max(prob, 70)
- If no positive state + strong acid: prob = min(prob, 5)

Clamp to [0, 100].
